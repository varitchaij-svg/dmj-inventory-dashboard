วัดโหลด GAS — เส้นฐาน Phase 0

ยิงหลาย request พร้อมกันเหมือนพนักงานเปิดแอปพร้อมกัน แล้วรายงานว่าเร็ว/ช้าแค่ไหน และมีกี่อันที่ ได้ HTML แทน JSON (= GAS ปฏิเสธเพราะล้น) · อ่านอย่างเดียว ไม่บันทึกอะไรลงชีต
ตั้งค่า
วิธีใช้ให้ได้ตัวเลขที่มีความหมาย
  1. รอบ "cache อุ่น" — กดยิงตอนไม่มีใครบันทึกอะไร → วัดกรณีดีที่สุด
  2. รอบ "cache หมดอายุพร้อมกัน" (สำคัญที่สุด) — ให้คนในร้านกดบันทึกอะไรสักอย่าง (สั่งของ/โอน/รับของ) แล้ว กดยิงทันที ภายใน 2-3 วิ → นี่คือ cache stampede ในแผนข้อ 7.3 ตัวที่จะพังก่อนเพื่อนตอน 15 คน
  3. เก็บผลทั้งสองรอบไว้เป็น เส้นฐาน แล้วรันซ้ำหลังแก้แต่ละ Phase เทียบกัน
เกณฑ์ผ่านตามแผน 7.5: เปิดแอปเห็นข้อมูล ≤ 3 วิ · ได้ HTML แทน JSON = 0%
